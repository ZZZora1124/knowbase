# 信号探测器 — 环境大脑捕获

以同等优先级捕获两类信号：

1. **原创思维** — 用户的想法、观察、论点、框架
2. **实体提及** — 人物、公司、项目、系统

原创思维的价值不低于实体提取。想法是智识资本，实体是索引。两者都会随时间复利增长。

## 契约

本 skill 保证：
- 每条消息都触发（纯操作性消息除外）
- 通过 hooks sidecar 异步运行，永不阻塞主响应
- 以用户的**原始措辞**捕获想法（禁止转述）
- 检测实体提及，创建/丰富 brain 页面
- 记录本次捕获内容的单行摘要日志
- 强制维护所有实体提及的反向链接（铁律）
- 每条写入的事实都有来源引用

**铁律：反向链接（强制）**

每次创建或更新提及某人或某公司的 brain 页面时：
1. 检查该人/公司是否有 brain 页面
2. 有 → 从其页面添加指向刚创建/更新页面的反向链接
3. 格式：`- **YYYY-MM-DD** | 被引用于 [页面标题](路径) — 简短上下文`
4. 未链接的提及 = 残缺的大脑

## 各阶段

### 阶段 1：想法/观察检测（首要）

当用户表达新颖的思想、观察、论点或框架时：
- 用户的**原创思维**（由用户产生）→ 创建/更新 `originals/<slug>`
- 用户引用的**世界概念** → 创建/更新 `concepts/<slug>`
- **产品或商业想法** → 创建/更新 `ideas/<slug>`

**捕获原始措辞。** 用户的语言本身就是洞见，不要转述。

**交叉链接（强制）：** 每个 original 必须链接到相关的人物、公司、会议和概念。
没有交叉链接的 original 是死 original。

### 阶段 2：实体检测（次要）

1. 提取实体提及（人物、公司、媒体标题）
2. 对每个实体：
   - `knowbase brain search "名称"` — 是否已有页面？
   - 无页面 → 判断是否值得记录。若值得，创建页面并丰富。
   - 页面存在但内容稀薄 → 触发丰富（服务端 Dream Phase 3.5 承接）
   - 页面存在且内容丰富 → 无操作
3. 有具体日期的新事实 → `knowbase brain timeline-add <slug> <date> "<摘要>"`

**自动链接：** `put_page` 的自动链接后处理钩子会自动从新页面创建到实体的链接，
无需手动调用链接命令。含具体日期的时间线条目仍需显式调用。

### 阶段 3：信号日志

始终记录单行摘要：
- `信号：0 个想法，0 个实体，0 条事实（跳过：操作性消息）`
- `信号：1 个想法（已捕获 → originals/x），2 个实体（已丰富 → people/y, companies/z）`

这使环境捕获循环可调试。

## 输出格式

对用户无可见输出。本 skill 在后台静默运行。
输出是创建/更新的 brain 页面和信号日志行。

## 写入格式（GBrain 标准 MD）

```markdown
---
type: person | company | project | concept | signal | original
title: <实体名>
tags: [<tag1>, <tag2>]
source: <来源描述>
date: <YYYY-MM-DD>
---

<compiled_truth：当前最佳综合理解，随新证据重写>

---

- **YYYY-MM-DD** | <事件类型> — <描述>
```

## 反模式

- 等待信号检测完成再返回主响应（阻塞）
- 转述用户原创思维而不是捕获原始措辞
- 为不值得记录的实体创建页面（一次性提及）
- 创建/更新页面后跳过反向链接
- 对纯操作性消息运行（"好的"、"谢谢"、"执行"）
